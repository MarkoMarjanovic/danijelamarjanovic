# Danijela Marjanović — Homepage Prototype v1

Version 1.1 responsive static HTML/CSS/JS concept, in Serbian Latin, based on the approved homepage copy and design direction. Includes the approved edited portrait under `assets/`.

## Open
Open `index.html` in a browser (requires internet connection to load the proposed Google Fonts; local serif/sans fallback fonts are provided).

For local development, run `python -m http.server 8000` inside this folder and visit `http://localhost:8000`.
