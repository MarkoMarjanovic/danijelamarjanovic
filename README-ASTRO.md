# Danijela Marjanović — multi-page Astro development branch

This is a working **review prototype**, not a published practice website. 

## Run locally

```bash
npm install
npm run dev
```

Build using `npm run build`. On Vercel choose **Astro** framework preset (build: `npm run build`, output: `dist`).

## Routes
- `/` homepage
- `/o-meni/`
- `/individualna-psihoterapija/`
- `/partnerska-psihoterapija/`
- `/moj-pristup/`
- `/cesta-pitanja/`
- `/kontakt/`
