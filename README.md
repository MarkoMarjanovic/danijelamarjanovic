# Danijela Marjanović — Psychotherapy Website

Responsive Serbian-language website MVP. Current version is a **design prototype**, not a production-ready client booking system.

## Run locally
Open `index.html` in a browser. No build step required.

## Deploy to Vercel
Import this GitHub repository into Vercel as **Other** (static site), with an empty build command and repository root as the output directory. Keep the deployment private or access-restricted until the professional/legal review, privacy policy, and booking integration are complete. The prototype deliberately sets `noindex,nofollow`.
